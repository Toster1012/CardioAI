# CardioAI: Аналитика данных и машинное обучение

Образовательная платформа для молодых медицинских работников: курс по анализу
данных и машинному обучению на реальных открытых кардиологических данных.

> Курс учебный. Модели и выводы из уроков не предназначены для принятия
> клинических решений.

Установка и запуск описаны в [INSTALL.md](INSTALL.md).
